# Chance & Shadow target architecture

## Containers
- Mobile/Web clients: presentation, local interaction state, no provider secrets.
- Relationship BFF: identity, consent, orchestration, idempotency and dossiers.
- FuFirE Calculation Plane: natal, HeHun, synastry, composite and transit calculations.
- Mapping Registry: source-reviewed native-to-neutral rules.
- Dynamic Polarity Engine: deterministic dynamic emission and abstention.
- Claim-safe Synthesis: wording only from released structured objects.
- Composer/Renderer: product manifests, PDF/poster and artifacts.

## Three variants
### Essential
Requires individual snapshots, core BaZi/HeHun and/or released synastry evidence, up to 3-4 dynamics. No composite or annual transits.

### Signature
Adds released composite module, wider evidence ledger, 5-7 dynamics and integrated thematic synthesis.

### Keepsake
Uses the same dossier and released modules; adds premium composition, dedication, poster and optional relationship-transit activation windows. No exclusive hidden calculation truth.

## Data flow
Client -> BFF -> provider modules -> schema validation -> evidence index -> mapping -> polarity -> claim validation -> UI/composer.
